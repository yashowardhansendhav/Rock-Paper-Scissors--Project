# Project Statement

## Project Title

Rock Paper Scissors Game

## Problem Statement

Rock Paper Scissors is a simple game that can be played between a person and a computer. The purpose of this project is to create the game using Python and apply basic programming concepts in a working project.

## Scope of the Project

The project allows a player to:

- Choose a difficulty level
- Play multiple rounds
- Choose rock, paper or scissors
- See the computer's choice
- See the result of each round
- Track wins, losses and draws
- View game history

## Target Users

The project is mainly designed for students and users who want to play a simple command-line game.

## High-Level Features

1. Rock Paper Scissors gameplay
2. Three difficulty levels
3. Multiple rounds
4. Score tracking
5. Game history
6. Input validation
