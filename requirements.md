# Project Requirements

## Functional Requirements

1. The user can select Easy, Medium or Hard difficulty.
2. The user can enter the number of rounds.
3. The user can enter rock, paper or scissors.
4. The program validates the user's choice.
5. The computer selects a choice.
6. The program determines the winner of each round.
7. The program updates wins, losses and draws.
8. The program stores the result of each round in game history.
9. The program displays the final score.
10. The program displays the game history.

## Non-Functional Requirements

### Usability
The game should be simple to understand and operate through the command line.

### Performance
The program should give the result of a round without unnecessary delay.

### Reliability
The program should handle invalid choices without stopping the game.

### Maintainability
The project is divided into separate Python files so that different parts of the game can be changed more easily.

### Resource Efficiency
The game should run using basic computer resources because it is a small command-line Python application.
