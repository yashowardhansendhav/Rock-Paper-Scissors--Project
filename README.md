# Rock Paper Scissors Game

## Overview

This is a simple Rock Paper Scissors game made using Python.

The player can choose rock, paper, or scissors and play against the computer.
The project also includes different difficulty levels, score tracking and game history.

## Features

- Rock Paper Scissors gameplay
- Easy, Medium and Hard difficulty
- Multiple rounds
- Player and computer choices
- Win, loss and draw score
- Game history
- Input validation

## Technologies Used

- Python
- Python IDLE / Command Prompt
- Jupyter Notebook
- Git and GitHub

## Project Files

- `main.py` - Runs the main game
- `game.py` - Checks the winner
- `difficulty.py` - Controls computer difficulty
- `score.py` - Stores the score
- `history.py` - Stores and displays game history
- `validation.py` - Checks player input
- `config.py` - Stores game choices and difficulty levels
- `Rock_Paper_Scissors.ipynb` - Notebook version of the project

## How to Run

1. Install Python.
2. Open Command Prompt.
3. Go to the project folder.
4. Run:

```text
py main.py
